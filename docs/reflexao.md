A principal vantagem na utilização de branch está na divisão e organização do desenvolvimento simultâneo entre todos os participantes. Enquanto a utilização de pull requests garante que as alterações possa ser revisadas antes
de aplicadas a branch main, além de resolver problemas de conflitos de merge. Esses conflitos de merge ocorre quando o git não sabe escolher entre diferentes alterações no mesmo trecho de código vindo de commits diferentes,
resolvemos o conflito eliminando uma das alterações e escolhendo a nova alteração do ultimo PR. O uso de PRs é extremamente necessário para a validação do código, sendo um dos tópicos mais importantes na utilização
do GitHub em projetos.
