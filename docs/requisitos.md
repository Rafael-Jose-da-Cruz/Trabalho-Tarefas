📋 Documento de Requisitos — Aplicativo de Lista de Tarefas

Este documento apresenta as principais funcionalidades, características e regras do aplicativo web “Lista de Tarefas”, desenvolvido pela equipe formada por Gregory, Luiz e Henrique.

1. Requisitos Funcionais (RF)

Os requisitos funcionais definem as ações e recursos que o sistema deve disponibilizar ao usuário.

* RF01: O aplicativo deve possibilitar o cadastro de uma nova tarefa por meio de um campo de entrada de texto.
* RF02: Ao selecionar o botão, a tarefa informada deve ser adicionada à lista.
* RF03: O usuário também deve conseguir cadastrar uma tarefa pressionando a tecla Enter.
* RF04: Todas as tarefas cadastradas devem ser apresentadas de forma organizada em uma lista.
* RF05: Cada tarefa deve possuir um botão de exclusão, permitindo que o usuário a remova.
* RF06: Cada tarefa deve possuir um botão de conclusão, permitindo concluir a tarefa.

2. Requisitos Não Funcionais (RNF)

Os requisitos não funcionais estabelecem as características técnicas, visuais e de qualidade que o aplicativo deve apresentar.

* RNF01: O projeto deve utilizar exclusivamente HTML5, CSS3 e JavaScript Vanilla, sem a utilização de frameworks externos.
* RNF02: A interface deve apresentar um visual simples, moderno e organizado, facilitando a utilização do aplicativo.
* RNF03: Os elementos interativos devem apresentar feedback visual ao usuário. Por exemplo, os botões devem utilizar o cursor pointer e apresentar efeitos visuais ao passar o mouse sobre eles (hover).
* RNF05: O aplicativo deve apresentar bom desempenho, carregando a interface e executando as ações do usuário de forma rápida e sem travamentos perceptíveis.
